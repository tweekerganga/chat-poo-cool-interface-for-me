📜 Standard IRC Commands
Action Description Command
Join Enter a specific channel. /join #channel
Part Exit the channel. Optional message shown to others. /part [#channel] [message]
Nick Changes your nickname to a new one. /nick nickname
Message Send a private message without opening a window. /msg nickname message
Query Open a private conversation window. /query nickname [message]
Emote Perform an action in text (e.g. * Nickname waves). /me action
Quit Disconnect from the whole network. /quit [message]
Ignore Stop seeing messages from a specific user. /ignore nickname
Unignore See messages from a user again. /unignore nickname
List Ignores Show everyone you currently have muted. /ignores
Whois Get information about a user (Idle time, etc). /whois nickname
Topic Check or change the current room's topic. /topic [#channel] [newtopic]
Invite Ask a user to join you in a channel. /invite nickname #channel
Away Mark yourself as currently unavailable. /away [reason]
